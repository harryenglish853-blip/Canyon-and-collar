## Measurements
- Cuts at ~5.7, 6.6, 8.2, 10.0, 19.7, 20.7, 28.0, 31.0 + many punch-ins between: a new framing
  every 1.5-4s, a new location every 5-10s.
- Speech: ~165 wpm, gaps between sentences trimmed to ~0.1-0.3s.
- Loudness of the post: about -19.5 LUFS integrated as captured, LRA 2.9 LU (heavily compressed
  voice). We deliver at -14 LUFS (platform target) with the same tight compression.
- Captions: lead words ~6% of frame width per letter-height (66px @1080w), hero words ~150px
  heavy, giant hook ~220px thin. Centred, between face and waist; hooks in the top third.
- Colours: purple gradient #e9b8ff -> #b05cff -> #7a2be0; cyan #d9fbff -> #5fe0ee -> #1aa7c4;
  neon yellow #fff36b with #ffe600 / #ffc400 / #ff9d00 glow; silver white -> #8e949c.
- Grade: saturated greens, warm skin, lifted shadows, gentle bloom, vignette.

## What makes it work (apply to any topic)
1. Hook line with a hero word in the first second.
2. Credibility number early (count it up, show the proof).
3. A "So, let's talk about how" pivot with a visual reset (zoom-blur, giant word).
4. A simple framework ("2 things") made visual (pills).
5. Each supporting claim gets one illustrative graphic.
6. Values list (one hero word each).
7. Call to action / promise, delivered in clean single-word captions, then loop to the opening shot.
